Drag & drop, paste Ctrl + V, atau pilih file → upload langsung ke GitHub.

Akses upload masih terkunci.
Pengaturan token GitHub (cukup sekali di browser ini)

Masukkan password upload di atas, lalu simpan token GitHub. Token dienkripsi di penyimpanan browser dan setelah itu upload cukup memakai password.

Catatan: GitHub Pages adalah situs statis. Password ini hanya membuka token yang tersimpan di browser, bukan menggantikan autentikasi GitHub di server.
